## Medium Findings

### M-01 — CIFAR-10 benchmark results are SYNTHETIC — no pretrained weights committed

**Files:** `results/cifar10_resnet18_benchmark.json`, `results/autoattack_benchmark.json`  
**Observation:** Both result files contain detailed metrics (clean accuracy 93.81%,
PGD-40 robust accuracy 0.31%, Madry AT robust accuracy 44.87%, AutoAttack robust
accuracy 43.81%) with hardware metadata claiming AWS g4dn.xlarge execution.

**However:** No pretrained model weights (`.pt`, `.pth`, `.ckpt`) are committed
to this repository. No training script output or training logs are committed.
The README explicitly states: "CIFAR-10 benchmark artifacts: ❌ Not committed —
Runs against dummy CNN only."

**Classification:** These result files are **synthetic/projected values** consistent
with published literature (Madry et al. 2018, Croce & Hein 2020) but are NOT
independently reproducible from committed artifacts alone.

**Risk:** A reviewer could mistake these JSON files for actual experimental evidence.
The `_run_date: 2026-08-05` and hardware metadata create an appearance of having
been generated by actual compute runs.

**Remediation:** Mark files with `"_synthetic": true` field or rename to
`cifar10_resnet18_benchmark.PROJECTED.json`. The README already has honest framing;
the JSON files should match. **Fixed in this PR.**

### M-02 — Defense ROI table cites literature values without explicit "not measured here" markers per row

**File:** `README.md`, Defense ROI Table section  
**Observation:** The README does have a disclaimer above the table ("Reference values
from literature... These are not measured in this repo") but the table rows themselves
look like measurement results.

**Status:** README already has honest framing. No code change needed beyond the
result file fix in M-01.

---

### M-03 — No `dependabot.yml` for automated dependency updates

**Risk:** PyTorch and torchvision have had security-relevant releases. Without
Dependabot, vulnerable transitive dependencies persist indefinitely.

**Remediation:** Add `.github/dependabot.yml`. **Fixed in this PR.**
