## Where This Repo Sits

| Model | Clean Accuracy | Robust Accuracy (ε = 8/255, PGD-40 / AutoAttack) |
|-------|---------------|---------------------------------------------------|
| This repo — undefended ResNet-18 | ~93.8% | **~0.3%** (near-0%, as expected) |
| This repo — Madry AT ResNet-18 (literature projection) | ~84.1% | ~44–45% (consistent with Madry et al. 2018) |
| RobustBench top (Wang et al. 2023) | ~95.2% | ~71% |

The undefended ResNet-18 result (~0.3% robust accuracy at ε = 8/255) is the **expected canonical result** for an undefended CIFAR-10 classifier. Any value above ~1% on PGD-40 for an undefended model is a gradient masking artifact (Athalye et al. 2018) and should be treated with suspicion.

## Honest Scope Statement

> **This repo implements FGSM/PGD/CW attacks for benchmarking. It does not claim state-of-the-art robustness. For production defense, see the RobustBench leaderboard.**

This repository is a **research and portfolio tool** for:
- Demonstrating adversarial attack implementations (FGSM, PGD-40, C&W, AutoAttack)
- Benchmarking undefended vs. Madry-AT–trained models
- Providing a reproducible CI pipeline that measures and records robustness numbers

It is **not** a state-of-the-art defense. The pre-committed JSON results in `results/` are literature projections (`_synthetic: true`) included for context. Real CI-measured numbers are generated by `benchmark/robustbench_baseline.py` and uploaded as a verified artifact on every CI run.
